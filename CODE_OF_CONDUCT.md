# Community conduct

Treat contributors and users with respect. Critique the work and explain your reasoning without personal attacks. Welcome questions and different experience levels.

Harassment, discrimination, threats, sexual harassment, doxxing, spam, and sharing private information without consent are unacceptable in issues, pull requests, discussions, and other project spaces.

The maintainer may edit or remove content, close or lock conversations, and restrict participation according to the severity and recurrence of the behaviour. Apply these rules consistently, including to maintainers.

Report public conduct problems using GitHub's **Report content** controls. For a private report involving project conduct, use [GitHub's abuse reporting form](https://support.github.com/contact/report-abuse) and identify the repository and relevant links. Do not disclose someone else's private information in a public report. Security vulnerabilities use the separate [security reporting process](SECURITY.md).
