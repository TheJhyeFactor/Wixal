# Wixal icon options

Four editable SVG options and matching 1024 × 1024 PNGs, with transparent corners. All preserve the Wixal W and cursor. comparison.png includes large previews and 32px/64px checks. These are alternatives; the active app icon has not been changed.

- Sakura: pink ceramic tile with a pale mark.
- Midnight: dark violet tile with a lavender cursor.
- Pearl: warm light tile with a graphite mark.
- Copper: charcoal tile with a copper mark.
