# Wixal icon options

Ten theme-matched editable SVG options and matching 1024 × 1024 PNGs, with transparent corners, plus the independent Copper option. All preserve the Wixal W and cursor. The native Appearance settings can match the running Dock icon to the theme or keep an independently selected icon. The bundle/Finder icon stays unchanged.

- Sakura: pink ceramic tile with a pale mark.
- Midnight: dark violet tile with a lavender cursor.
- Pearl: warm light tile with a graphite mark.
- Copper: charcoal tile with a copper mark.

New matching options: Cloud (frosted blue), Paper (ivory and espresso), Dune (sandstone and terracotta), Graphite (slate and silver), Forest (pine and sage), Aurora (deep teal with a violet cursor), and Obsidian (near-black and copper).

Regenerate the seven additional colourways with `node native/scripts/generate-theme-icons.cjs`. The generator reuses the existing vector mark and requires the project's `sharp` build dependency. The existing `comparison.png` shows the original four options only.
