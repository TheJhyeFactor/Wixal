MODEL CONTEXT PROTOCOL
External tools
Connect a trusted local MCP server for tools such as linters or image services. Connect launches its executable on your Mac with your user permissions. Servers may use the network. Wixal reviews tool calls; server startup itself can perform actions.
Use a server’s secure credential setup. Avoid putting secrets in arguments, which are saved locally. Servers reconnect only when you click Connect.
